# Security

Please report a vulnerability privately, through [a GitHub security advisory](https://github.com/bottrall/acp-sdk/security/advisories/new), rather than in a public issue. Say which version it affects, and how to reproduce it.

You'll hear back within a week. Once a fix is released, the advisory is published with credit to you, unless you'd rather not be named.

## Supported versions

Security fixes go into the latest release of acp-sdk only.
